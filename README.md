## Publish to GitHub Pages
1. Download and extract the ZIP.
2. Open https://github.com/abdulnaazrj-pixel and choose the repository used for your portfolio.
3. Upload `index.html` to the repository root (replace the old file if prompted).
4. Commit the change to your main branch.
5. Open **Settings → Pages**.
6. Under **Build and deployment**, select **Deploy from a branch**.
7. Choose **main** and **/(root)**, then Save.
8. Wait for the published URL to appear in Settings → Pages.
